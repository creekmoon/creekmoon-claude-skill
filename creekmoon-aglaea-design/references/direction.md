# 视觉方向决策

方向模式的产出是一组决策，不是页面代码：一句话视觉主张（气质、材质、能量感）、色彩基调、字体选择、间距与圆角策略、主要页面的布局形态。定完方向再进入构建。

已有设计体系的项目不要走这里——沿用现有令牌和惯例，本文件只服务于从零建立方向。

## 第一步：选轨道

| 轨道 | 覆盖 | 优化目标 |
|------|------|---------|
| **产品界面** | 后台、看板、管理台、设置页、内部工具、开发者工具 | 信息密度、安静的 chrome、可扫视性、工具文案 |
| **营销页面** | 落地页、官网、定价页、作品集、推广页 | 视觉冲击、叙事、单一转化路径 |

判断歧义时：SaaS 产品的官网是营销轨道，登录后的应用是产品轨道——两者分开设计，不共用一套视觉密度。一句话检验：**说服陌生人 = 营销；让操作者干活 = 产品。**

把营销轨道套在产品界面上，就会出现"看板顶上放 hero 区、卡片里写口号"的灾难（见 anti-patterns.md）。

## 第二步：定个性

先明确语境：谁在用（角色）、在什么场景用（每天 8 小时 vs 偶尔一瞥）、情绪目标是什么（可靠、专业、亲切、锐利）。然后从个性矩阵里选一个，不要既要又要：

| 个性 | 适合 | 视觉表达 |
|------|------|---------|
| 精密紧凑 | 开发者工具、监控、专业操作台 | 高密度、小字号、冷灰、细边框、等宽数字 |
| 信任稳重 | 金融、企业服务、审批流 | 中性偏暖、层级分明、克制的蓝/绿主色、无花哨动效 |
| 温和亲切 | 面向普通用户的工具、内容产品 | 稍大的字号与留白、暖灰、柔和圆角、友好文案 |
| 大胆现代 | 创新产品的营销面、创意工具 | 强对比、大字标题、有个性的主色、演出性动效 |
| 数据分析 | BI、报表、看板 | 图表优先、语义色严格、大量 tabular 数字、极简 chrome |

## 第三步：定色彩基调

1. **中性色温**：冷（偏蓝，技术感）/ 暖（偏棕，亲和感）/ 纯中性（最安全但最平），三选一。
2. **明暗**：浅色为主 / 暗色为主 / 双主题。开发者工具和监控类适合暗色优先；面向普通用户的后台默认浅色。
3. **一个主色**：从产品气质出发选择，避开"没想法就 indigo"。参考锚点：蓝（可靠，最不会错但最平）、绿（增长/金融/健康）、橙（能量/效率工具）、青绿（冷静的现代感）、品牌色（已有 VI 时直接继承）。
4. 语义色四件套（success/warning/danger/info）与主色区分开：主色若是绿，success 就要偏移色相或明度，不能撞车。

产出直接落成 tokens.md 模板里的 CSS 变量。

## 第四步：定字体与排版气质

- 中文界面默认系统字体栈（见 tokens.md），这不是妥协——系统栈渲染质量和加载速度都最优。品牌确有需要再上 webfont（MiSans、HarmonyOS Sans、思源黑体），并做子集化。
- 排版气质靠参数不靠换字体：紧凑个性用小字号 + 收紧行高 + 600 标题；亲切个性用 14-16px 正文 + 1.6 行高 + 500 标题。
- 营销页大标题可以考虑有个性的西文展示字体搭配中文黑体，但正文永远回到系统栈。

## 第五步：定布局与密度

从 layout.md 的骨架里选主布局（侧栏 / 顶导航 / 分栏 / 居中单列），并定密度档位：紧凑（表格行 36px、卡片 padding 16px）/ 默认（40-44px、20px）/ 宽松（48px+、24px）。密度是方向决策的一部分，之后所有页面统一，不要每页各自发挥。

## 参考产品校准

用这些产品校准"好"的标准（是校准，不是抄皮——成品要像自己产品的品类）：

| 产品 | 学什么 |
|------|--------|
| Linear | 克制的配色、高密度但不乱、键盘优先的产品 UI |
| Stripe（后台） | 金融级信任感、表格与数据展示、文档式清晰 |
| Vercel / Zed | 极简 chrome、黑白灰骨架 + 单一强调色、开发者工具气质 |
| Raycast | 暗色优先的打磨、锐利图标、快的手感 |
| Notion / 飞书 | 面向普通用户的亲和密度、协作产品的层级组织 |
| Things 3 | 冷静宽松的布局、友好但不幼稚 |
| OpenAI / ElevenLabs（官网） | 排版驱动的编辑部式极简、自信的留白（营销轨道） |

## 输出格式

方向模式的交付物：

```markdown
## 视觉方向

**主张**：[一句话：气质 + 材质 + 能量感，如"冷静精密的工程工具，深灰骨架配单一青绿强调，动效近乎隐形"]

**轨道**：产品界面 / 营销页面
**个性**：[矩阵中的选择 + 一句理由]
**色彩**：中性色温 [冷/暖/中]，[浅色/暗色/双主题]，主色 [色值 + 理由]
**字体**：[字体栈 + 字号基准 + 标题字重]
**布局**：[主骨架] + [密度档位]
**圆角/深度**：[圆角系统] + [深度策略四选一]

**令牌草案**：[tokens.md 模板填入实际值]
```

交付后带着这组决策进入构建模式。
