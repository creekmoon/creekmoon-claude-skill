# 设计令牌（Tokens）

配色、字体、间距、圆角、阴影的具体规则和数值。构建任何 UI 前先确定这一层，全站只有一套，不要页面各自发挥。

## 配色系统

### 中性色（页面的骨架）

- 全站只用一套中性色阶。不用纯灰（`#808080` 这类 R=G=B），给中性色一点色温倾向：冷灰偏蓝（类 slate，适合工具/技术产品），暖灰偏棕（类 stone，适合内容/生活产品）。
- 文本建立 4 级对比层级，示例（浅色模式）：

| 层级 | 用途 | 参考值 |
|------|------|--------|
| primary | 标题、正文、数据 | `#18181B` |
| secondary | 次要说明、表头 | `#52525B` |
| muted | 占位、辅助信息 | `#A1A1AA` |
| faint | 分隔线、禁用 | `#E4E4E7` |

- 背景层级：页面底色、内容表面、悬浮表面最多三层，相邻层级差异要小（例如 `#FAFAFA` / `#FFFFFF` / `#FFFFFF`+阴影），靠细微差异表达结构，不靠大色块。

### 主色（accent）

- 全站一个主色，只用于：主按钮、链接、激活/选中态、焦点环、进度指示。
- 产品界面里主色的视觉占比应低于 5%。主色到处都是时，真正的主操作就消失了。
- 禁止直接使用 Tailwind 默认 `indigo-600` + `gray-*` 组合作为"没想法时的默认"——这是最典型的 AI 生成味。主色必须是一个有意识的选择（见 direction.md 的色彩基调决策）。
- **第二典型的默认组合：高端消费品牌的"米白 + 黄铜"**。做器物、手作、家居、健康、轻奢这类品牌时，大模型必然伸手去拿：奶油米白底（`#F5F1EA`、`#FBF8F1`、`#EFEAE0` 一族）+ 黄铜/陶土/赭石/暗红 accent（`#B08947`、`#B6553A`、`#9A2436` 一族）+ 咖啡色近黑文字（`#1A1714` 一族）。每个这类品牌都长成同一张脸，品牌本身就消失了。默认禁用，换成下面任一族并轮换使用：冷奢（银灰 + 铬 + 烟灰）、森林（深绿 + 骨白 + 琥珀）、黑与棕褐（真正的近黑 + 暖棕褐，锐对比、不掺米白）、钴蓝 + 奶油、赤陶 + 冷灰、橄榄 + 砖红 + 纸白、纯黑白 + 一个高饱和亮色。只有品牌规范点名了这些颜色，或气质确实是复古手作且你能说清为什么这个具体配色配这个具体品牌时，才用回米白黄铜。

### 语义色

- success / warning / danger / info 各一个，全站唯一映射，不挪作装饰。
- 状态色的常见形态：低饱和浅底 + 深色文字的徽章（例如 success：底 `#ECFDF5`、文字 `#047857`），而不是高饱和实心块。
- 危险操作按钮用 danger 色实心，且一个界面里尽量只出现一个实心红按钮。

### 对比度

- 正文文字对比度 ≥ 4.5:1；大字（≥19px 粗体或 ≥24px）和图标 ≥ 3:1。
- muted 层级也要保证可读，`#A1A1AA` 在白底上约 2.9:1，只能用于占位符和辅助图标，不能承载必读信息。

### 暗色模式

- 背景不用纯黑，用 `#0A0A0B` ~ `#141416` 区间；文字不用纯白，用 `#EDEDEF` 左右。
- 层级表达方式反转：浅色模式靠阴影，暗色模式靠"表面越高越亮" + 1px 边框（`rgba(255,255,255,0.08)` 左右）。阴影在暗底上几乎不可见，直接移除或极弱化。
- 语义色和主色在暗色下降低饱和、提高亮度，否则会刺眼。
- 主题切换瞬间禁用过渡：`[data-theme-switching] * { transition: none !important }`，否则所有带色属性会同时动画。

### 起始模板

新项目没有既定主题时，从这套 CSS 变量起步（主色按 direction.md 决策替换）：

```css
:root {
  /* 中性色：冷灰示例 */
  --bg-page: #FAFAFA;
  --bg-surface: #FFFFFF;
  --text-primary: #18181B;
  --text-secondary: #52525B;
  --text-muted: #A1A1AA;
  --border: #E4E4E7;
  --border-strong: #D4D4D8;

  /* 主色与语义色（示例值，需按方向决策替换） */
  --accent: #4F46E5;
  --accent-hover: #4338CA;
  --success: #047857;
  --success-bg: #ECFDF5;
  --warning: #B45309;
  --warning-bg: #FFFBEB;
  --danger: #B91C1C;
  --danger-bg: #FEF2F2;

  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;

  /* 动效：命名曲线与时长档位（用法见 motion.md） */
  --ease-enter: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-move: cubic-bezier(0.25, 1, 0.5, 1);
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
  --duration-fast: 150ms;
  --duration-base: 200ms;
  --duration-slow: 300ms;
}

.dark {
  --bg-page: #0E0E10;
  --bg-surface: #17171A;
  --text-primary: #EDEDEF;
  --text-secondary: #A1A1AA;
  --text-muted: #6B6B74;
  --border: rgba(255, 255, 255, 0.08);
  --border-strong: rgba(255, 255, 255, 0.14);
}
```

## 字体

### 字体栈

中文界面默认字体栈：

```css
font-family: system-ui, -apple-system, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

- 系统栈已经足够好，引入 webfont（如 MiSans、HarmonyOS Sans、思源黑体）只在品牌确有需要时做，并注意中文字体体积（需子集化）。
- 数据、ID、金额、代码用等宽或 `font-variant-numeric: tabular-nums`。
- 字体一律自托管或走框架的字体方案（`next/font`、`@font-face` + `font-display: swap`），不要在生产环境用 `<link>` 直连 Google Fonts。

### 西文展示字体与衬线纪律

只在营销页、作品集需要西文大标题时涉及这一层；产品界面用系统栈就够。

- **"创意 / 高级 / 编辑部感 = 上衬线"是大模型最容易被识破的判断**。默认用无衬线展示字体（Geist Display、Cabinet Grotesk、PP Neue Montreal、GT Walsheim 一类）。无衬线不等于无聊，它是默认，就像黑色是时装的默认。
- 衬线只在两种情况下成立：品牌规范里点名了某个衬线字体；或气质确实是出版 / 奢侈 / 古籍 / 复古，且你能说清这个具体衬线为什么配这个具体品牌。
- 别默认 `Fraunces` 和 `Instrument Serif`——这两个是大模型最爱的展示衬线，出现即露馅。确实要用衬线时在池子里轮换（PP Editorial New、GT Sectra、Reckless Neue、Tiempos Headline、Recoleta、Playfair Display、EB Garamond 等），不要连续两个项目用同一个。
- **强调标题里的某个词，用同一字体的斜体或加粗**，不要在无衬线标题里插一个衬线词（或反过来）。混家族强调是业余做法。中文黑体标题搭配西文展示字体属于跨语种搭配，不在这条禁令里。
- **斜体降部裁切**：展示字号下的斜体词如果含 `y g j p q`，`leading-none` / `leading-[1]` 会把降部切掉。至少给 `leading-[1.1]`，并在外层留 `pb-1` 余量。交付前逐个检查标题里的斜体词。

### 字号阶梯

| 字号 | 用途 |
|------|------|
| 12px | 徽章、表格辅助列、时间戳等最次要信息 |
| 13px | 数据密集表格正文、次要说明 |
| 14px | 后台界面正文默认 |
| 16px | 强调正文、表单输入文字 |
| 18-20px | 区块/卡片标题 |
| 24-30px | 页面标题 |

- 中文正文不小于 13px；12px 只用于辅助信息。
- 层级尽量用相邻 2 档表达，一个页面出现超过 5 种字号说明层级设计失控了。

### 行高与字重

- 标题行高 1.2-1.3，正文 1.5-1.6（中文字形复杂，行高比西文习惯略大）。
- 中文可用字重少，层级主要靠 400（正文）/ 500（小标题、强调）/ 600（标题、数据）三档；避免大面积 700+。
- 中文正文不加 `letter-spacing`；大号西文标题可用 -0.01em ~ -0.02em 收紧。
- 标题避免孤字成行：能用 `text-wrap: balance` 就用。

## 间距

- **4px 网格**：所有间距、尺寸取 4 的倍数。常用阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- **内边距对称**：卡片、按钮、输入框左右上下对称，除非有明确视觉理由（如带图标的按钮）。
- **亲密性原则**：组内间距必须小于组间间距。label 离自己的输入框（4-8px）要比离上一个字段（16-24px）近；小标题离下方内容要比离上一个区块近。违反亲密性是"页面看着乱"的最常见原因。
- **密度匹配场景**：数据密集页（表格行高 36-44px、卡片 padding 16px）不要套用营销页的大留白；营销页反之。操作者需要扫视，不需要呼吸感。

## 圆角

- 全站一套圆角系统，示例：4px（小控件：徽章、复选框）/ 8px（按钮、输入框、卡片）/ 12px（大容器、弹窗）/ 9999px（胶囊徽章、头像）。
- **同心圆角公式**：嵌套元素的外层圆角 = 内层圆角 + 两者间距。例如内部元素圆角 4px、间距 8px，外层容器就用 12px；反过来先定外层 12px、padding 8px，内层就取 4px。嵌套圆角不同心是生产环境 UI 最常见的隐形视觉错误。
- 小控件不用大圆角：32px 高的按钮配 16px 圆角会显得玩具感，配 6-8px 才稳。

## 阴影与深度

- **只选一种深度策略**，全站一致：纯边框 / 微阴影 / 分层阴影 / 表面色阶。
- 分层阴影公式（卡片、输入框、悬浮容器通用）：

```css
box-shadow:
  0 0 0 1px rgba(0, 0, 0, 0.06),
  0 1px 2px -1px rgba(0, 0, 0, 0.06),
  0 2px 4px 0 rgba(0, 0, 0, 0.04);
```

hover 时每层透明度 +0.02，配 `transition: box-shadow 200ms ease`。

- 非纯白背景上优先用 `box-shadow`（含 1px spread 的描边层）而不是 `border`：rgba 透明度能适应任何底色，实色边框不能。
- 图片加 1px 内描边增加质感，用 `outline` 不占布局：

```css
img {
  outline: 1px solid rgba(0, 0, 0, 0.1);
  outline-offset: -1px;
}
.dark img { outline-color: rgba(255, 255, 255, 0.1); }
```

- 弹窗、下拉菜单等真正悬浮的元素阴影可以更重，但页面内静态卡片保持轻。阴影浮夸是廉价感的直接来源。
