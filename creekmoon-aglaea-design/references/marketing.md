# 营销页面规则

本文件只服务**营销轨道**：官网首页、产品介绍页、定价页、作品集、活动推广页——给还没用上产品的陌生人看的页面。轨道判断见 direction.md 第一步：说服陌生人 = 营销，让操作者干活 = 产品。

产品界面（后台、看板、管理台、内部工具）不要读这里，很多规则是相反的——看 layout.md 和 components.md。

营销页的失败模式和产品界面完全不同：产品界面死于"元素堆砌、密度失控"，营销页死于"每个区块长得一样、首屏装不下、通篇没有一张真图"。

## 首屏硬规则

一屏装不下的首屏就是坏首屏。以下每条不满足都算没做完：

- **首屏必须在初始视口内完整成立**：标题最多 2 行，副文案 ≤ 20 词（中文约 40 字）且不超过 4 行，主 CTA 不滚动就能看见。装不下就缩字号或砍文案，绝不能让 CTA 掉到屏幕外。说不清价值主张时，是价值主张不清楚，不是这条规则太紧。
- **字号和主视觉尺寸一起规划**：标题超过 6 个词就不要起手最大字号。常规区间是 `text-4xl md:text-5xl lg:text-6xl`，只有 3-5 词的短标题才配 `text-6xl md:text-7xl`。**4 行的首屏标题永远是字号错误，不是文案太长。**
- **顶部内边距上限 `pt-24`（约 6rem）**。再多首屏内容就会浮在视口中间，读起来像布局 bug 而不是刻意留白。需要更透气就放大字号或主视觉，不要加顶部间距。
- **首屏最多 4 个文字元素**：眉标签或品牌条（二选一，或都不要）、标题、副文案、CTA（1 主 + 最多 1 次）。禁止塞进首屏：CTA 下方的小字补充（"支持 GitHub、GitLab 和自建 Git"）、信任小条（"XX 团队正在使用"）、价格预告、功能要点列表、头像社会证明排。这些全部下移到首屏正下方的独立区块。
- **"正在使用"的 logo 墙属于首屏下方的独立区块**，不要和首屏文案挤在同一行里。
- **首屏必须有真实主视觉**。文字 + 渐变色块不是首屏，是占位。

## 导航

- 桌面端导航必须单行。1024px 处装不下就精简文案、砍次要项、或收进汉堡菜单。桌面端两行导航是坏设计。
- 导航高度上限 80px，默认 64-72px。不要做吃掉 15% 视口的巨型导航。

## 区块布局多样性

营销页最常见的失败是每个区块长得一样，读起来像模板。

- **同一布局家族一页只用一次**：三列图文卡、整宽引用、左文右图分栏……用过就换。8 个区块的落地页至少要有 4 种不同布局家族。"精选案例"不能长得和"我们能做什么"一样。
- **左右图文交替最多连续 2 段**。第三段连续的图文分栏就是失败，用整宽区块、纵向堆叠、bento、跑马灯打断节奏。
- **眉标签限额：每 3 个区块最多 1 个**。眉标签指标题上方那行小号大写宽字距标签（`SELECTED WORK`、`四种配色`，典型写法 `text-[11px] uppercase tracking-[0.18em]`）。AI 生成的页面给每个区块都配一个，产出的是同一种模板节奏。首屏那个算一个，9 个区块最多 3 个。机械检查法：数 `uppercase tracking` 类小标签的出现次数，超过 `ceil(区块数 / 3)` 就不合格。删掉时不需要替代品——标题本身够了，区块在页面上的位置已经说明了它是什么。
- **禁用 split-header**：左边巨大标题、右边一小段说明文字漂在右列（左 7/8 列 + 右 4/5 列小正文）。一个区块只该有一个焦点。确实需要标题加说明就纵向堆叠（标题在上、正文在下、限宽 65 字符）。右列只在承载真实视觉或交互元素时才成立。
- **bento 格子数必须等于内容数**：3 项内容就 3 格（1+2、2+1 或不对称三联），5 项就 5 格。中间或末尾出现空格子说明网格没规划好，重排网格，不要贴一个空白块凑数。
- **bento 不能是 6 个白底白字的文字卡**：任何多格网格里至少 2-3 格要有真实视觉变化（真图、品牌化渐变、纹理、色调底）。米白底配米白卡、格子里只有排版，即使别处做得好也读作 AI 默认。
- **反居中偏好**：变化度中档以上时避开"居中大标题 + 居中副文案"的首屏，改用左右分栏、左文右图、不对称留白或滚动钉住。例外是宣言式、发布公告式页面——信息本身就是设计，居中成立。
- 每个多列区块都要在同一个组件里写明 768px 以下的塌缩方式，不要假设"框架会自己处理"。

## 内容密度与文案

营销页活在第一印象上，不活在通读上。删是默认动作。

- **单区块默认形状**：短标题（≤ 8 词）+ 短段落（≤ 25 词）+ 一个视觉或一个 CTA。超出这个形状要有理由。
- **不做数据倾泻区块**：20 行文献表、30 项获奖列表、巨型价格矩阵放在营销页上都是选错了组件。改成"前 3-5 条亮点 + 查看全部"、跑马灯、或干脆独立成页——数据本身是产品时，它该有自己的页面。
- **超过 5 项的列表要换组件，不是把列表拉长**。默认 `<ul>` 或每行一条 `divide-y` 是最懒的选择。替代方案：两列分组、图卡网格、可分类就用 tab 或折叠、横向滚动 pill、跑马灯（大量不需要单独注意的条目）。
- **参数表的具体替代**（硬件、器物、服饰、手作类品牌最容易踩）：每项一张卡，卡上是参数名 + 大号数值 + 一句"为什么重要"，桌面两列移动一列；或横向滚动 pill；或把 10 项参数归成 3 个逻辑组，每组一条分隔线加组标题；或 3-4 项做成大号展示磁贴、其余收进"查看完整参数"。**10 行参数每行一条细线是最差的默认。**
- **交付前把页面上每个可见字符串重读一遍**（标题、副标、眉标签、按钮文案、正文、图注、alt 文本、页脚、错误提示），标记出：语法破碎的、指代不明的、像 AI 幻觉的（可爱但不通的双关、硬造的比喻）、像大模型在假装深刻的（自谦式做作、匠人味标签、故作诗意的小字）。逐条重写。不确定是否通顺就换成一句平实的功能句——**AI 生成的可爱文案比朴素文案更糟。**
- **假精确数字要处理**：`92%`、`4.1×`、`48k`、`5.8mm` 只有两种情况可以留——来自真实数据，或明确标注为示例。其余是伪造品牌并未声称的工程精度，删掉。
- **一页一种语域**：技术味（`47 tasks · 0.6 ctx-switches/day`）、编辑部散文、营销爆点不要混在同一个页面里，除非品牌语调本来如此。
- **引用与推荐语**：正文最多 3 行，原文更长就剪——落地页上的引用是片段不是全文；署名写"姓名 + 角色（+ 公司）"，不要只有名字；引号用真正的排印引号或干脆不用。
- **CTA 文案**：主 CTA 最多 3 词、理想 1-2 词。桌面端不允许换行——换行的 CTA 就是坏的，要么缩短文案要么放宽按钮，不要给 CTA 设 `max-width`。
- **同一意图的 CTA 全站只用一种说法**："联系我们"、"聊一聊"、"开始合作"、"说说你的项目"是同一个意图，导航、首屏、页脚必须统一成一个。同理"免费试用/立即开始/免费注册"、"查看作品/精选案例/浏览项目"。
- 西文文案不要用 em-dash（`—`）做节奏装饰，这是最容易被识别的大模型笔迹；用句号、逗号、括号或冒号重组句子。

## 视觉素材

落地页和作品集是**视觉产品**。纯文字页面加上 div 拼的假截图，等于半成品。

素材来源优先级：

1. **环境里有图像生成工具就必须用**，按区块生成对应素材（首屏主图、产品图、纹理背景、氛围图），按该区块需要的比例生成。不要因为手写 CSS 更快就跳过这一步。
2. **没有生成工具就用真实图源**：`https://picsum.photos/seed/{描述性种子}/{宽}/{高}` 做摄影占位（种子要能描述区块内容），或品牌提供的真实素材。
3. **两者都不行就明确挂占位**：写成 `<!-- TODO: 首屏产品图 1600x1200 -->`，并在交付说明里列出所有需要真实图片的位置请用户提供。绝不用手搓 SVG 插画或 div 假截图把页面填满。

- **即使极简风格也需要真实图片**。纯文字不是极简，是没做完。克制风格的站点至少也要 2-3 张真实图片（首屏、一张产品或场景、一张辅助图）；风格克制就生成黑白摄影，不要因为"简约"就不放图。
- **社会证明用真 logo**：不要用 `<span>Acme Co</span>` 排一行文字充当 logo 墙。真实品牌用 Simple Icons（`https://cdn.simpleicons.org/{slug}/{颜色}`）或 devicon；虚构品牌就顺手生成一个简单字母标记（单字母圆底、双字母连写、抽象图形）作为内联 SVG。确保浅色和暗色模式下都能看清。
- **logo 墙只放 logo**：不要在每个 logo 下面标行业分类（`Vercel` 底下写"托管"、`Stripe` 底下写"支付"）。logo 本身就是可信度，分类标签不提供任何新信息。
- **禁止 div 拼假截图**：用 `<div>` 矩形堆出的假任务列表、假仪表盘、假终端窗口是第一号 AI 痕迹。要展示产品就用真实截图、生成图、或在页面里嵌一个真的迷你组件；做不到就干脆不放预览，用编辑部式摄影代替。
- 手搓装饰性 SVG（自定义插画、品牌图形）默认不做，除非用户明确要求，或它只是一个极简几何标记。图标库的图标不在此列（见 components.md）。

## 营销页专属 AI 痕迹

产品界面的痕迹清单在 anti-patterns.md，下面这些是营销页和作品集特有的，默认全部禁止，除非需求明确要求：

| 痕迹 | 改法 |
|------|------|
| 首屏眉标签写版本号（`V0.6`、`BETA`、`INVITE-ONLY`、`EARLY ACCESS`） | 删掉，除非页面本身就是在讲发布状态 |
| 区块编号式眉标签（`00 / INDEX`、`001 · 能力`、`06 · 怎么运作`） | 眉标签只用平实语言点题，不做枚举；或直接删 |
| 图片和磁贴上的 `01 / 4` 分页标记 | 用户数得清，不需要标 |
| 中点 `·` 当万能分隔符（`foo · bar · baz · qux`） | 每行最多 1 个；需要分隔改用换行、细线或分列 |
| 每个导航项、列表行、徽章前加彩色小圆点 | 默认零装饰圆点；只有表达真实状态（服务在线、档期可约）才留，且一屏一处 |
| `<br>` 断行 + 斜体的标题（`for thirty<br>*years.*`） | 标题先做到自然可读，玩花样要有品牌理由 |
| 竖排旋转文字（`INDEX OF WORK, 2018-2026` 转 90°） | 作品集陈词；只在明确要实验性风格且构图真需要时用 |
| 十字准线、细网格线纯装饰 | 只有在组织真实内容时才画线 |
| 假版本页脚（`v1.4.2`、`Build 0048`、`last sync 4s ago · main`） | 这是命令行工具的陈设，营销页禁止 |
| "Quietly trusted by"、"低调服务于"式社会证明标题 | 用平实说法（"正在使用"、"客户包括"），logo 够说话就不要标题 |
| "Field notes"、"来自现场"、"案头随笔"式诗意栏目名 | 用功能性标签（"客户评价"、"最新文章"、"正在做的事"）或不标 |
| 城市/时间/天气条（`LIS 14:23 · 18°C`、导航里的地名） | 除非品牌真跟地点或跨时区相关；页脚写联系地址可以，氛围条不行 |
| 眉标签下面的小字自述（"这些都是今天就能用的功能，不是路线图承诺。"） | 眉标签 + 标题 + 正文已经够了，删掉 |
| 通用步骤标签（`阶段 1 / 阶段 2`、`Step 1 / 2 / 3`、`Phase 01`） | 步骤内容本身就是标签，直接写动作（"安装"、"配置"、"上线"） |
| 图片上叠 pill 标签（`品牌 · 02`、`PLATE · BRAND`） | 让图片自己说话，或把说明放到图片下方（图外） |
| 装饰性图注（`Field study no. 12 · Ines Caetano`、`Frame XII · 35mm`） | 只有真实摄影师需要署名时才写；否则删掉或写一句功能性说明 |
| 首屏底部的装饰文字条（`BRAND. MOTION. SPATIAL.`、`DESIGN · BUILD · SHIP`） | 删掉；只在承载真实链接或真实状态时保留 |
| 区块标题右上角漂着的小段说明 | 移到标题正下方，或做成真正对齐的两列，不要角落浮字 |
| 滚动提示（`Scroll`、`↓ 向下滚动`、滚轮动画） | 删掉。用户还没滚动时正在看首屏，他们知道什么是滚动 |
| 带底槽的评分/进度条当对比可视化 | 用数字 + 小图标，或无底槽的细条；大灰底槽是后台组件，放营销页是杂物 |
| "预订 412 / 800"式实时库存计数器 | 只有真是限量预售且有真实数据时才用 |
| 长列表每行都有上下边框 | 二选一且用得稀疏，或换组件（见"内容密度"一节） |
| 整页主题中途反转（暗色页面里夹一段米白区块） | 一页只有一个主题；同主题内的底色微差（`zinc-950` 挨着 `zinc-900`）可以，翻到 `amber-50` 就是坏的。刻意的一次性主题切换要配强过渡，一页最多一次 |
| 跑马灯满天飞 | 横向滚动文字带一页最多一个，两个以上读作偷懒填充 |

## 交付前自检

产品界面的质量闸门在 SKILL.md，营销页额外过这几条：

- 首屏一屏装得下：标题 ≤2 行、副文案 ≤20 词、CTA 不滚动可见、字号与主视觉一起规划过。
- 首屏文字元素 ≤4 个，没有小字补充条、信任条、价格预告。
- 导航桌面端单行，高度 ≤80px。
- 眉标签数量 ≤ `ceil(区块数 / 3)`。
- 8 个区块至少 4 种布局家族；没有连续 3 段左右图文交替；没有 split-header。
- bento 格子数 = 内容数，且至少 2-3 格有真实视觉变化。
- 所有 CTA 桌面端不换行；同一意图只有一种文案。
- 每个可见字符串重读过，没有语法破碎和 AI 味文案；假精确数字已处理。
- 真实图片到位（生成 / 真实图源 / 明确占位三者之一），没有 div 假截图，没有纯文字页。
- 整页一个主题、一个主色、一套圆角，没有中途反转。
- 跑马灯一页最多一个；每个动画都能用一句话说清它在传达什么。
- 按钮文字与按钮底色、占位符与表单底色的对比度都过 WCAG AA（白底白字的 CTA、无边框的透明按钮压在图片上，都是常见事故）。
