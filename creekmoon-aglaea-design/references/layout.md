# 布局与页面形态

先定页面形态，再定布局骨架，最后排信息分区。跳过前两步直接摆组件，是布局呆板的根源。

## 第一步：判断页面形态

页面形态由用户任务决定，不由内容数量决定。先回答：用户来这个页面，是要**感知全局**、**找到对象并操作**、**理解单个对象**、**提交信息**，还是**按步骤推进**？

| 形态 | 用户任务 | 布局要点 |
|------|---------|---------|
| 看板 Dashboard | 感知状态、发现异常、看趋势 | 指标要有主次和关联（状态→原因→影响→入口），不是等大卡片阵列；异常要能点进去 |
| 管理台 Console | 筛选、批量处理、进详情 | 筛选区紧贴结果区；表格是主角，占最大面积；批量操作在选中后出现 |
| 详情页 Detail | 理解单个对象、执行动作 | 顶部对象摘要（名称、状态、主操作），下方分区展示属性/历史/关联 |
| 表单页 Form | 提交一件事 | 单列布局，相关字段分组，主按钮在末尾左对齐或吸底；不要双列表单 |
| 工作流 Workflow | 按步骤推进 | 当前步骤、已完成、未完成清晰；说明卡住的前置条件；支持回退 |
| 落地页 Landing | 被说服、转化 | 一条主转化路径、一个重复出现的 CTA、证据（案例/数据/口碑）就近支撑主张 |

页面同时承担多种任务时（混合形态），明确哪个任务是主线，其余内容降级为侧栏、抽屉、标签页或二级页面，不要平铺。

## 第二步：选布局骨架

| 骨架 | 适用 | 备注 |
|------|------|------|
| 侧边栏 + 内容区 | 多模块后台的默认选择 | 侧栏 220-260px，可折叠；内容区才是主角，侧栏视觉上要安静 |
| 顶部导航 + 内容区 | 模块少（≤5）或内容需要全宽 | 导航高 48-64px；二级导航用页内 tab |
| 列表-详情分栏 | 邮件式：左列表右详情 | 列表列 320-400px；选中态要明显；移动端退化为两级页面 |
| 上下分层 | 先全局摘要再明细 | 顶部摘要区收紧（一行关键数字），大面积留给明细表 |
| 居中单列 | 表单、登录、设置、文章 | 内容宽度 480-720px；登录页不需要左右分屏放插画，除非品牌确有素材 |

营销页面的分区排布：hero（一句话主张 + 主 CTA）→ 产品实证（截图/演示）→ 特性分组 → 社会证明 → 定价 → 尾部 CTA。每个区块只讲一件事，删掉重复表达同一情绪的区块。

## 第三步：信息分区

把页面内容归入四类，按优先级排位：

- **核心决策区**：用户必须先看的状态、结论、关键数据、风险——放首屏最高视觉权重的位置。
- **辅助信息区**：解释、历史、明细、参考——可折叠、可下钻、可放次要位置。
- **操作区**：主操作与判断依据相邻；危险操作与普通操作物理分离；每屏只有一个主按钮。
- **反馈状态区**：加载、空数据、错误、成功的呈现位置，设计阶段就要预留（见 components.md 状态设计）。

排序原则：

- 首屏只放做出下一步判断所需的信息。能下钻的不并列，能折叠的不抢首屏，能筛选得到的不重复展示。
- 解释性内容紧贴被解释对象，不要集中堆到页面底部。
- 指标之间要有关系（因果、对比、递进、阈值），没有关系的并列数字应该删除、合并或降级进表格。

## 栅格、宽度与响应式

- 内容区最大宽度：数据密集页可全宽（留 24-32px 边距）；阅读型内容限制 640-720px；营销页区块 1080-1200px 居中。
- 正文行宽不超过 65-75 字符（中文约 35-40 字），超过就分栏或限宽。
- 桌面优先设计的后台也要保证 768px 宽度可用：侧栏折叠、表格横向滚动或降列、操作收进菜单。
- 移动端触控目标 ≥ 44px 高。
- 断点处布局整体切换（三列→单列、侧栏→抽屉），不要让元素以百分比连续挤压变形。

## 密度与留白

- 留白用于分组和节奏，不是越多越高级。数据密集页过度留白会逼操作者滚动而不是扫视。
- 分组优先用间距和 1px 分隔线表达；卡片只在"这个块是独立交互单元"时使用。整页卡片套卡片说明分组逻辑没想清楚。
- 工作面要比导航和 chrome（头部、侧栏、工具条）响亮：用户到达页面后，导航应该在视觉上退后（降低对比度、缩小图标），把注意力让给内容。
- 每条工具栏只做一件事：位置/上下文、视图控制、页面操作分开放，不要混在一根横条里。

## 低保真先行

写样式前先用 ASCII 骨架确认结构，例如管理台：

```text
┌──────────┬──────────────────────────────────────┐
│ 侧栏      │ 页面标题                    [主操作]  │
│ (安静)    ├──────────────────────────────────────┤
│          │ [筛选] [筛选] [搜索____]     共 128 条 │
│          ├──────────────────────────────────────┤
│          │ 表格（主角，占最大面积）                │
│          │  名称    状态    数量↗   更新时间  操作 │
│          │  ...                                  │
│          ├──────────────────────────────────────┤
│          │ 分页                                   │
└──────────┴──────────────────────────────────────┘
```

结构确认了"先看什么、再做什么"成立，再进入视觉实现。
