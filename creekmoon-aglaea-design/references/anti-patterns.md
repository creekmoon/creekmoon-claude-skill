# 反 AI 模板清单

AI 生成页面的典型痕迹，按布局、配色、组件、文案四类列出。打磨模式下逐条对照，构建模式交付前自检。每条都给出改法——目标不是"避开某种样式"，而是回到"这个元素为任务做了什么"。

判断总纲：**删除优先于装饰**。发现问题时，第一反应是删掉或降级这个元素，而不是给它换一种样式。结构应该被感受到，而不是被看到。

打磨范围限于呈现层：可以重排分组、降级卡片、收紧密度、改写文案，但不改变信息集合与任务流——缺状态、流程绕、信息优先级错这类问题属于上游（creekmoon-topaz-pm）职责，标注出来建议走上游，不擅自改。

## 布局类

| 信号 | 为什么差 | 改法 |
|------|---------|------|
| 卡片马赛克墙：整页由等大卡片铺满，层级来自网格而不是内容 | 所有东西同等响亮 = 没有重点 | 按信息分区重排：主内容占大面积，次要信息降级为列表/侧栏；卡片只留给独立交互单元 |
| 后台页顶部放 hero 区（大标题 + 副标题 + 渐变背景） | 操作者要工作面，不要被欢迎 | 删掉 hero，首行直接放页面标题 + 主操作 + 工作内容（表格/图表/表单） |
| 三列等宽特性卡（图标 + 标题 + 两行描述）出现在产品界面 | 这是落地页模板，不是工作界面 | 改为列表或表格；如果内容本来就少，用一段说明文字 |
| 巨型 KPI 卡片堆：四个等大数字卡片一字排开，互不关联 | 无主次、无关联的数字没有决策价值 | 确定主指标放大，其余收进一行紧凑摘要；有关系的指标（现状→趋势→异常）排成链路 |
| 数据表格塞进居中窄列 | 浪费横向空间，逼用户滚动 | 数据密集内容用全宽，只给 24-32px 页边距 |
| 每个区块之间留白巨大，一屏只能看到一个区块 | 呼吸感属于营销页；操作者需要扫视 | 收紧到 4px 网格的合理档位（区块间 32-48px），提高信息密度 |
| 到处都是分割卡片但没有一处真正的视觉重心 | 分组手段单一化 | 用留白 + 分隔线 + 小标题分组，删掉不承载交互的卡片边界 |

## 配色类

| 信号 | 为什么差 | 改法 |
|------|---------|------|
| 紫色/蓝紫渐变背景或按钮 | 2023 年后 AI 生成页的标志性印记 | 换成有意识选择的单色主色（见 direction.md），渐变只在营销页且服务品牌时用 |
| Tailwind 默认 indigo-600 + gray-* 直接上 | 默认值 = 没有决策 | 中性色换成带色温的一套（slate/stone/zinc 择一），主色按产品气质选 |
| 多个高饱和 accent 并存（蓝按钮、紫链接、青图标） | 颜色打架，状态色失去语义 | 收敛到一个主色 + 语义色四件套，其余全部回归中性色 |
| 每个图标一个彩色圆底 | 颜色变成装饰，扫视成本上升 | 图标用 `currentColor` 跟随文字层级，删掉底色块 |
| 状态色当装饰用（绿色标题、红色强调非危险内容） | 语义被稀释，真正的状态反而读不出来 | 颜色只用于状态和动作；强调用字重和字号 |
| 大面积玻璃拟态（backdrop-blur + 半透明白） | 廉价的"高级感"套皮，损害可读性 | 回到实色表面 + 一种深度策略；blur 只留给真正悬浮的遮罩层 |
| 暗色模式 = 纯黑底 + 纯白字 + 原样阴影 | 对比过冲刺眼，阴影在暗底失效 | 底色 #0E0E10 档、文字 #EDEDEF 档、阴影换 1px 亮边框、降饱和 |

## 组件类

| 信号 | 为什么差 | 改法 |
|------|---------|------|
| 每个卡片标题旁一个无意义图标 | 图标不传递信息就是噪音 | 删掉；图标只留给动作、类型、状态 |
| 小按钮配大圆角（32px 高配 16px 圆角） | 玩具感，和数据界面气质冲突 | 按钮/输入框圆角 6-8px，胶囊形只给徽章和头像 |
| 所有元素都有阴影，或阴影浓重发黑 | 全都浮起来 = 没有层次 | 一种深度策略；静态卡片用 1px 边框或极轻分层阴影，重阴影只给弹层 |
| hover 时元素放大 + 上浮 + 阴影加深全套 | 过度反馈，高频交互变得聒噪 | hover 只做一件事：背景微变或阴影微增，150-200ms |
| 按钮加载时变成一个圆 spinner，宽度塌缩 | 布局跳动 | 保持按钮宽度，spinner 与文案并存 |
| 空状态只有一张插画 + "暂无数据" | 用户不知道为什么空、接下来干什么 | 写明原因 + 给下一步动作按钮 |
| 每个区块都从零自己长出来（进场动画满天飞） | 用户什么都没做，页面自己表演 | 删掉挂载动画；动效只响应用户操作 |

## 文案类

| 信号 | 为什么差 | 改法 |
|------|---------|------|
| 工作界面出现营销口号（"释放数据的力量"） | 操作者需要位置和动作，不需要被推销 | 区块标题写"这是什么/能干什么"："已选指标"、"同步状态"、"搜索成员" |
| "强大的"、"智能的"、"一站式"、"轻松管理" | 空洞形容词，零信息量 | 说具体能力："支持批量导入 CSV"、"每 5 分钟自动同步" |
| 按钮文案"确定/提交"配危险操作 | 用户不知道确认的是什么 | 按钮写明动作和对象："删除 3 个项目" |
| 每个区块配一句副标题，且都在重复主标题 | 复读机式填充 | 副标题只在补充新信息（范围、频率、行为）时存在，否则删 |
| 中英混杂无规则（"Dashboard 看板"、"点击 Submit"） | 术语不统一，认知负担 | 全站术语表：一个概念一个叫法，界面语言一致 |

## 自检问题

打磨或交付前问自己：

1. 把所有卡片边框隐藏，页面结构还成立吗？（成立说明卡片是多余的）
2. 把所有颜色去掉只留黑白，还能看出主次和状态入口吗？（层级不能只靠颜色）
3. 每个图标遮住，信息有损失吗？（无损失就删）
4. 每句文案，是在帮用户定位/判断/操作，还是在自我介绍？
5. 这个页面截图发给同行，对方会说"这是 AI 生成的"还是"这是谁设计的"？
